# ADR 0003：本机验收边界——只生成不跑，真实的留给 3090

- 状态：已采纳（2026-09-22，用户选定）
- 背景：开发机无 GPU，跑不了 YOLO；用「微型模拟实验」可以在本机验证执行路径，但模拟实验不是用户要跑的东西，验证价值有限还增加维护面。
- 决策：
  1. 本机验收聚焦「设计 + 配置生成 + 报告 + 分析」：design/plan/analyze/next/report 全链路、双后端、可比性守卫、预算/超时/中断护栏；
  2. 真实执行路径保留**唯一一个** plumbing 测试与审计项（`echo` 级命令，明确标注「管线验证，非科学实验」），用来证明子进程、日志、指标解析、resume 真的接通了；
  3. YOLO 实战与 Qwen 后端属于 3090 交接清单（README 给出整段命令），本机不声称已验证。
- 理由：验收证据必须与真实验证目标一致；「没跑过就说跑过」是本项目最不能犯的错（§1 硬性原则）。
- 代价：执行路径的覆盖面比全量实测窄——由 plumbing + 单元测试（注入假执行层）补足，并在 §24 明示边界。
